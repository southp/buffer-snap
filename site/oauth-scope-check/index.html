Buffer OAuth scope check

Runs Buffer's Authorization Code flow with PKCE, then shows which scopes Buffer granted and whether a refresh token came back. Token values are never shown or stored: each response is reduced to its field names and scope, then dropped.

Reproduce

  1. In this browser, sign in to buffer.com as account A.
  2. Click Start attempt and approve. Expected: offline_access granted, refresh token ✅.
  3. Click Start attempt again. On Buffer's page, switch to account B, then approve. Observed: offline_access missing, no refresh token ❌.
  4. Click Start attempt once more, already signed in as B. Observed: ✅ again.

Note what you did on Buffer's page in each row, then click Copy report.
