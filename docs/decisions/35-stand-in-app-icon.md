# Use a hand-drawn bolt and viewfinder as a stand-in app icon

**Decision:** The icon is a white bolt inside viewfinder corners on a blue gradient, drawn as an SVG in the repo and
rendered to a single 1024×1024 PNG. It's a stand-in until there's final branding.

**Why:** The bolt ties it to the sign-in screen, and the corners say "capture". A bolt alone looked like any flashlight
or charging app. The sign-in screen's own bolt couldn't be reused because it's an SF Symbol, which Apple's terms don't
allow in app icons, and Buffer's logo isn't ours to use. Rejected: hand-made dark and tinted variants, which aren't
worth the effort for a stand-in when iOS can derive them from the default icon.
