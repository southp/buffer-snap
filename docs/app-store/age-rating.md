# Age rating

App Store Connect → the app → **App Information** → **Age Rating** → Edit. Expected result: **4+**.

BufSnap shows only what the user said or typed, their own Buffer sign-in page, and its own screens. Nothing comes
from other people, so every answer is the lowest one. Apple words and groups the questions differently from time to
time: answer anything not listed here by the same rule.

## Features and capabilities

| Question | Answer | Why |
|---|---|---|
| Parental controls | No | None in the app |
| Age assurance | No | It doesn't check ages |
| Unrestricted web access | **No** | The only web page is Buffer's sign-in, in Apple's sign-in sheet, which can't browse elsewhere |
| User-generated content | **No** | Users write only to their own Buffer account, and the app shows no one else's content |
| Messaging and chat | No | None |
| Advertising | No | None |
| Health or wellness topics | No | None |
